Funciones de la Materia

A través de la realización de estos proyectos, he consolidado una base sólida en el desarrollo web Front-End. He aprendido a estructurar información compleja utilizando HTML5, implementando desde tablas de datos estructurados hasta formularios interactivos con validaciones.

Complementando la estructura, he aplicado CSS3 para el diseño visual, dominando el posicionamiento de elementos (absoluto, relativo y fijo) y el uso de Media Queries para crear diseños responsivos adaptables a diferentes dispositivos. Finalmente, he integrado la lógica mediante JavaScript, utilizando estructuras de control, bucles y manipulación del DOM para dotar de interactividad y dinamismo a las aplicaciones.
