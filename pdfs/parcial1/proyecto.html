Etiquetas Semánticas

Función: Estas etiquetas le dan un significado estructural al contenido. Ayudan a los navegadores, motores de búsqueda y lectores de pantalla a entender mejor la organización de tu página. Organizan el contenido en bloques lógicos.

  • <header>: Contiene la cabecera, usualmente con el logo y el menú principal.
  • <nav>: Define un bloque de enlaces de navegación.
  • <main>: Representa el contenido principal y único de la página.
  • <section>: Agrupa contenido relacionado temáticamente.
  • <article>: Contiene un bloque de contenido independiente y autocontenido (como un post de blog).
  • <footer>: Representa el pie de página, con información de copyright, enlaces, etc.
<body>
  <header>
    <h1>Logo de Mi Sitio</h1>
    <nav> ... </nav>
  </header>

  <main>
    <article> ... </article>
  </main>

  <footer>
    <p>© 2025 Mi Sitio Web.</p>
  </footer>
</body>

<aside>

Función: Define contenido relacionado al contenido principal, pero que podría considerarse separado (como una barra lateral o un bloque de anuncios).

<main>
  <h1>Artículo Principal</h1>
  <p>Contenido del artículo...</p>
</main>
<aside>
  <h3>Artículos Relacionados</h3>
  <ul>...</ul>
</aside>

<figure> y <figcaption>

Función: <figure> se usa para agrupar contenido multimedia como imágenes, diagramas o fragmentos de código. <figcaption> proporciona una leyenda o título para el <figure>.

<figure>
  <img src="paisaje.jpg" alt="Un paisaje montañoso">
  <figcaption>Fig.1 - Vista de las montañas al amanecer.</figcaption>
</figure>

<details> y <summary>

Función: Crean un widget de revelación interactivo. El contenido dentro de <details> está oculto y se muestra al hacer clic en el texto de <summary>.

<details>
  <summary>Ver más información</summary>
  <p>Aquí está el contenido adicional que estaba oculto.</p>
</details>

<address>

Función: Proporciona información de contacto para el autor o propietario de un documento o artículo. Puede incluir nombres, direcciones de correo, URL, direcciones físicas, etc.

<address>
  Escrito por <a href="mailto:autor@ejemplo.com">Juan Pérez</a>.<br>
  Visítanos en:<br>
  MiSitio.com<br>
  Calle Falsa 123, Ciudad<br>
</address>

<div>

Función: Es un contenedor genérico en bloque. No tiene significado semántico, pero es fundamental para agrupar elementos y aplicarles estilos con CSS o manipularlos con JavaScript.

<div class="noticia">
  <h2>Título de la noticia</h2>
  <p>Contenido de la noticia.</p>
</div>

<span>

Función: Es un contenedor genérico en línea. Se usa para agrupar una parte de un texto o documento con el fin de aplicarle un estilo específico sin romper el flujo del contenido.

<p>El precio final es <span style="color: green; font-weight: bold;">$19.99</span>.</p>

<hr>

Función: Representa una ruptura temática entre párrafos o secciones. Se visualiza como una línea horizontal.

<p>Este es el primer tema.</p>
<hr>
<p>Este es un tema completamente diferente.</p>

<h1> a <h6>

Función: Define encabezados o títulos. <h1> es el más importante y <h6> el menos. Son cruciales para la estructura y el SEO.

<h1>Título Principal de la Página</h1>
<h2>Un Subtítulo Importante</h2>

<p>

Función: Define un párrafo. Es la etiqueta básica para agrupar texto.

<p>Este es el texto de un párrafo.</p>

<pre>

Función: Define texto preformateado. El texto dentro de esta etiqueta se muestra en una fuente de ancho fijo (como la de código) y respeta tanto los espacios como los saltos de línea.

<pre>
  Texto con    múltiples
  espacios y
  saltos de línea.
</pre>

<blockquote>

Función: Se utiliza para marcar una sección que es una cita extensa de otra fuente. Los navegadores suelen renderizarlo con un margen (indentación).

<blockquote cite="https://www.fuente.com">
  <p>Esta es una cita larga de un libro o un artículo.</p>
</blockquote>

<a>

Función: Crea un hipervínculo. El atributo href indica el destino del enlace.

<a href="https://www.google.com">Ir a Google</a>

<strong> y <em>

Función: Se usan para dar énfasis al texto.

  • <strong>: Indica que el texto tiene una gran importancia o seriedad (visualmente en negrita).
  • <em> (emphasis): Pone énfasis en una palabra o frase (visualmente en cursiva).
<p><strong>Advertencia:</strong> No tocar el cableado.</p>
<p>Debes hacerlo <em>ahora</em> mismo.</p>

<b>, <i>, <u> y <small>

Función: Estas etiquetas aplican formato estilístico sin un significado semántico fuerte.

  • <b>: Pone el texto en negrita (Bold).
  • <i>: Pone el texto en cursiva (Italic).
  • <u>: Subraya el texto (Underline).
  • <small>: Muestra el texto en un tamaño más pequeño, como en el "texto legal".
<p>Este texto es <b>importante</b> pero no tanto como con <i>strong</i>.</p>

<ins> y <del>

Función: Marcan ediciones en el documento.

  • <ins>: Marca texto que ha sido insertado.
  • <del>: Marca texto que ha sido eliminado.
<p>El precio es <del>$100</del> <ins>$75</ins>.</p>

<sub> y <sup>

Función: Se usan para texto de subíndice y superíndice.

  • <sub>: Subíndice, como en H2O.
  • <sup>: Superíndice, como en E=mc2.
<p>La fórmula del agua es H<sub>2</sub>O.</p>
<p>El área es de 100 m<sup>2</sup>.</p>

<code>, <kbd>, <samp>, <var>

Función: Etiquetas para representar diferentes tipos de texto técnico o de computadora.

  • <code>: Muestra un fragmento de código. Ejemplo: <div>.
  • <kbd>: Representa la entrada del usuario (teclado). Ejemplo: Ctrl + S.
  • <samp>: Indica una salida de muestra de un programa.
  • <var>: Representa una variable en una expresión matemática o de programación.
<p>Para guardar, presiona <kbd>Ctrl+S</kbd>.</p>
<p>La variable <var>x</var> debe ser mayor que cero.</p>

<q> y <cite>

Función: Se usan para citas.

  • <q>: Para una cita corta en línea. Los navegadores suelen añadir comillas automáticamente.
  • <cite>: Para citar el título de una obra (libro, película, etc.).
<p>Como dijo Einstein, <q>La imaginación es más importante que el conocimiento</q>.</p>
<p>Mi libro favorito es <cite>Cien Años de Soledad</cite>.</p>

<abbr>

Función: Define una abreviatura o un acrónimo. El atributo title se usa para mostrar el término completo.

La <abbr title="Organización Mundial de la Salud">OMS</abbr> emitió un comunicado.

<time>

Función: Define una fecha u hora específica. El atributo datetime proporciona un formato legible por máquinas.

La reunión será el <time datetime="2025-10-31T10:00">31 de Octubre a las 10:00 AM</time>.

<mark>

Función: Resalta una porción de texto que es relevante en un contexto particular, como resaltar términos de búsqueda en un resultado.

Resultados de la búsqueda: <mark>HTML</mark> es un lenguaje de marcado.

<br>

Función: Inserta un salto de línea. Es útil para separar líneas cortas de texto, como en direcciones o poemas, sin crear un nuevo párrafo.

Google LLC<br>
1600 Amphitheatre Parkway<br>
Mountain View, CA 94043

<ul>, <ol>, <li>

Función: Crean listas.

  • <ul>: Lista no ordenada (con viñetas).
  • <ol>: Lista ordenada (con números o letras).
  • <li>: Elemento de la lista (se usa dentro de <ul> o <ol>).
<h3>Lista de compras:</h3>
<ul>
  <li>Leche</li>
  <li>Pan</li>
</ul>

<h3>Instrucciones:</h3>
<ol>
  <li>Abrir la caja.</li>
  <li>Montar las piezas.</li>
</ol>

<dl>, <dt>, <dd>

Función: Crean una lista de descripción, que consiste en pares de términos y sus descripciones (como un glosario).

  • <dl>: El contenedor de la lista (Description List).
  • <dt>: El término a definir (Description Term).
  • <dd>: La descripción del término (Description Details).
<dl>
  <dt>HTML</dt>
  <dd>Lenguaje de Marcado de Hipertexto.</dd>
  <dt>CSS</dt>
  <dd>Hojas de Estilo en Cascada.</dd>
</dl>

<table>

Función: Define una tabla para mostrar datos tabulares.

<table>
  ... filas y celdas aquí ...
</table>

<thead>, <tbody>, <tr>, <th>, <td>

Función: Son las partes que componen una tabla bien estructurada.

  • <thead>: Agrupa el contenido de la cabecera de la tabla.
  • <tbody>: Agrupa el contenido del cuerpo principal de la tabla.
  • <tr>: Define una fila (table row).
  • <th>: Define una celda de encabezado (table header).
  • <td>: Define una celda de datos (table data).
<table>
  <thead>
    <tr>
      <th>Nombre</th>
      <th>Edad</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>Ana</td>
      <td>25</td>
    </tr>
  </tbody>
</table>

<caption> y <tfoot>

Función: Elementos adicionales para tablas.

  • <caption>: Proporciona un título o leyenda para la tabla. Debe ser el primer elemento hijo de <table>.
  • <tfoot>: Agrupa el contenido del pie de la tabla, como filas de resumen o totales.
<table>
  <caption>Gastos Mensuales</caption>
  <thead>...</thead>
  <tbody>...</tbody>
  <tfoot>
    <tr>
      <td>Total</td>
      <td>$500</td>
    </tr>
  </tfoot>
</table>

<form>

Función: Contenedor para controles de formulario, como campos de texto, botones, etc.

<form action="/enviar-datos" method="post">
  ... campos del formulario aquí ...
</form>

<fieldset> y <legend>

Función: <fieldset> agrupa controles relacionados dentro de un formulario, dibujando un recuadro a su alrededor. <legend> proporciona un título para ese grupo.

<form>
  <fieldset>
    <legend>Información Personal</legend>
    <label for="nombre">Nombre:</label>
    <input type="text" id="nombre"><br>
    <label for="email">Email:</label>
    <input type="email" id="email">
  </fieldset>
</form>

<label>

Función: Representa una etiqueta descriptiva para un control de formulario. Mejora la accesibilidad, ya que al hacer clic en el label, el foco se pone en el campo asociado.

<label for="nombre">Tu nombre:</label>
<input type="text" id="nombre">

<input>

Función: Es el campo más versátil. El atributo type define su comportamiento: text, email, password, checkbox, radio, submit, etc.

<input type="email" placeholder="Escribe tu email">

<textarea>

Función: Define un campo de entrada de texto de múltiples líneas, ideal para comentarios o mensajes largos.

<label for="comentario">Comentario:</label>
<textarea id="comentario" rows="4" cols="50"></textarea>

<select> y <option>

Función: Crean un menú desplegable.

  • <select>: Es el contenedor del menú.
  • <option>: Cada una de las opciones dentro del menú.
<label for="pais">Elige un país:</label>
<select id="pais">
  <option value="mx">México</option>
  <option value="es">España</option>
  <option value="ar">Argentina</option>
</select>

<optgroup>

Función: Se usa dentro de un <select> para agrupar opciones relacionadas. El atributo label define el título del grupo.

<select>
  <optgroup label="Europa">
    <option value="es">España</option>
    <option value="fr">Francia</option>
  </optgroup>
  <optgroup label="América">
    <option value="mx">México</option>
    <option value="ar">Argentina</option>
  </optgroup>
</select>

<datalist>

Función: Contiene un conjunto de elementos <option> que representan sugerencias para un campo <input>. Proporciona una funcionalidad de autocompletado.

<label for="navegador">Elige tu navegador:</label>
<input list="navegadores" id="navegador" name="navegador">
<datalist id="navegadores">
  <option value="Chrome">
  <option value="Firefox">
  <option value="Safari">
</datalist>

<button>

Función: Define un botón clicable. Puede contener texto e incluso otras etiquetas como imágenes, a diferencia de <input type="submit">.

<button type="submit">Enviar Formulario</button>

<output>

Función: Representa el resultado de un cálculo o una acción del usuario. Es útil en formularios para mostrar resultados dinámicamente.

<form oninput="resultado.value=parseInt(a.value)+parseInt(b.value)">
  <input type="range" id="a" value="50"> +
  <input type="number" id="b" value="50"> =
  <output name="resultado" for="a b">100</output>
</form>

<progress>

Función: Muestra el progreso de una tarea. Se representa como una barra de progreso.

<label for="file">Progreso de descarga:</label>
<progress id="file" value="32" max="100"> 32% </progress>

<meter>

Función: Representa una medida escalar dentro de un rango conocido (un medidor). Es útil para mostrar uso de disco, relevancia de un resultado, etc.

<label for="disco">Uso de disco:</label>
<meter id="disco" value="0.6">60%</meter>

<img>

Función: Inserta una imagen. Requiere src (ruta de la imagen) y alt (texto alternativo para accesibilidad).

<img src="logo.png" alt="Logo de la empresa">

<picture> y <source>

Función: Permiten ofrecer diferentes versiones de una imagen para distintos tamaños de pantalla (responsive) o formatos. El navegador elegirá la <source> más adecuada.

<picture>
  <source media="(min-width: 800px)" srcset="imagen-grande.jpg">
  <source media="(min-width: 400px)" srcset="imagen-mediana.jpg">
  <img src="imagen-pequena.jpg" alt="Descripción">
</picture>

<audio> y <video>

Función: Incrustan contenido multimedia. El atributo controls muestra los controles de reproducción estándar del navegador (play, pausa, volumen).

<!-- Ejemplo de Audio -->
<audio controls src="mi_cancion.mp3">
  Tu navegador no soporta el elemento de audio.
</audio>

<!-- Ejemplo de Video -->
<video controls width="320" src="mi_video.mp4">
  Tu navegador no soporta el elemento de video.
</video>

<iframe>

Función: Inserta un documento HTML dentro de otro (un marco en línea). Se usa comúnmente para incrustar mapas, videos de YouTube o contenido de terceros.

<iframe src="https://www.google.com/maps/embed?..." width="600" height="450"></iframe>

<embed>

Función: Proporciona un punto de integración para una aplicación externa o contenido interactivo (un "plug-in"), como un archivo Flash (ahora obsoleto) o un visor de PDF.

<embed type="application/pdf" src="documento.pdf" width="600" height="500">

<object>

Función: Representa un recurso externo, que puede ser una imagen, un subdocumento HTML, o un recurso que necesita un plugin. Es más versátil pero más complejo que <embed>.

<object data="recurso.swf" type="application/x-shockwave-flash">
  <p>Contenido alternativo si el plugin no carga.</p>
</object>

<canvas>

Función: Se usa para dibujar gráficos, animaciones o visualizaciones sobre la marcha, generalmente a través de JavaScript.

<canvas id="miLienzo" width="200" height="100" style="border:1px solid #000;">
  Tu navegador no soporta canvas.
</canvas>

<script> y <noscript>

Función:

  • <script>: Se usa para incrustar o hacer referencia a código ejecutable, casi siempre JavaScript.
  • <noscript>: Define un contenido alternativo que se mostrará si el navegador no soporta scripts o si el usuario los ha desactivado.
<script>
  alert('¡Hola, mundo!');
</script>
<noscript>
  <p>Esta página requiere JavaScript para funcionar correctamente.</p>
</noscript>

Etiquetas de <head>

Función: La sección <head> contiene metadatos sobre el documento que no se muestran en la página.

  • <title>: Define el título del documento que se muestra en la pestaña del navegador.
  • <meta>: Proporciona metadatos como el conjunto de caracteres, descripción de la página, palabras clave, etc.
  • <link>: Se usa para vincular recursos externos, principalmente hojas de estilo CSS.
  • <style>: Contiene información de estilo (CSS) para el documento.
  • <base>: Especifica la URL base para todas las URL relativas en una página.
<head>
  <meta charset="UTF-8">
  <title>Mi Página Web</title>
  <link rel="stylesheet" href="styles.css">
</head>
